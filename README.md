# 生成AIを活用した漢字生成プロジェクト

本リポジトリでは、Stable Diffusion を用いて **英語の定義から漢字のイメージを生成** する実験を行った結果をまとめています。言語モデルや画像生成技術に興味がある方、あるいは漢字デザインの応用例を探している方の参考になれば幸いです。

---

## 1. プロジェクト概要

- **目的**  
  - Stable Diffusion 1.4 をベースモデルにし、英語の定義や説明文から独自の「漢字らしき画像」を生成する  
  - 漢字の芸術性や文化的要素を新しい視点で再解釈し、AI がどこまで創造性を発揮できるのかを検証

- **背景**  
  - 漢字は形状・構造が複雑で、芸術的要素も強い  
  - 大規模言語モデルや画像生成モデルの進化により、文字の画像化（フォント生成・新文字デザイン）分野への応用が期待される  
  - 本プロジェクトは個人研究として企画し、データセットや学習手法をカスタマイズして実験を実施

---

## 2. 実験レポート

- [Report-Project-Generative AI.pdf](./Report-Project-Generative%20AI.pdf)  
  上記PDFにて、実験の詳細を記載しています。
  1. **データ準備**: `kanjidic2.xml` から英語の定義を抽出し、SVGフォント画像とマッチング  
  2. **モデル設定**: Stable Diffusion をカスタマイズし、256×256程度の低解像度画像で学習  
  3. **結果例**:
     - **成功事例**: 「beautiful」→ 美しい感じの漢字を生成  
     - **失敗事例**: ブレ・潰れや文字構造の破綻が見られる  
     - **ユニーク事例**: 「Elon Musk」や「YouTube」など想定外の文字イメージ生成

---

## 3. 使用技術

1. **Stable Diffusion 1.4**  
   - 基盤となる生成モデル。英語テキスト→画像生成が可能  
2. **Python + PyTorch**  
   - モデルのカスタマイズ、データ処理、学習の実装を担当  
3. **kanjidic2.xml & SVGフォント**  
   - 漢字の定義・読み・形状情報を抽出し、画像データセットとして構築

## 5. 実行手順

1. **環境設定**  
   - Python 3.8+  
   - PyTorch, Transformers, 及び Stable Diffusion 関連ライブラリ (例: `diffusers`, `accelerate`)  
   - SVG → PNG変換用に Inkscape 等が必要な場合あり  
2. **データ準備**  
   - `kanjidic2.xml` と SVGフォントを `data/` 下に設置  
   - `main.py` または `generate_images.py` を実行し、英語定義とSVGのマッチング確認  
3. **学習 or 推論**  
   - `generate_images.py` などで推論テスト（例:「beautiful」→ 生成結果を保存）  
   - 任意で `main.py` 内のスクリプトを修正し再学習も可能

## 6. 結果・考察

- **成功例**  
  - 意味をそこそこ反映し、漢字としての体裁を保った画像が生成される  
- **失敗例**  
  - 誤ったストローク配置、ノイズの多い画像、読解不能な文字  
- **今後の改善**  
  - 学習データ増強 / 高解像度化 / モデルアーキテクチャの工夫
